ShinGan

Nano Banana Pro (Gemini 3 Pro Image) 画像生成エージェント。プロンプトカタログ、インタラクティブビルダー、バッチ生成、リファレンス画像管理をオールインワンで。

Prompt Catalog

10カテゴリ×20プロンプト。キャラクター、背景、UI、プロダクト、ロゴなど幅広いジャンルを網羅。

Prompt Builder

9ステップの構造化プロンプト生成。スタイル・構図・ライティングのプリセット付き。

Batch Generation

カテゴリ一括またはカスタムリストでのバッチ生成。大量のプロンプトを一度に処理。

Reference Images

グループベースのリファレンス画像管理。1グループ最大14枚まで。

Image Attach

ダッシュボードから画像をアタッチして管理。generate → pending → attach → completed のワークフロー。

REST API

FastAPI 24エンドポイント + Swagger自動ドキュメント。フル機能のAPI。

Quick Start

pip install -e .

# Dashboard (localhost:8080)
shingan serve

# CLI
shingan list                      # Prompt catalog
shingan show char-pixel-mascot    # Prompt details
shingan build                     # Interactive builder
shingan batch -c character        # Batch generate
shingan gen "A cute robot" -r 4K  # Free prompt

API Endpoints

shingan serve → http://localhost:8080 / Swagger: /docs
